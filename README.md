# Marionette — project page

Static project page for *Marionette: Predicting World States, Rendering Geometry, Painting
Appearance* ([arXiv:2608.14530](https://arxiv.org/abs/2608.14530)).

**This is the `gh-pages` branch.** `main` of the same repository is the open-source inference
code. One repo, two branches, one name — so the paper, the page and the code all point at
`AlayaLab/Marionette`.

**Status: live** at <https://alayalab.github.io/Marionette/> since 2026-08-16. Pages serves the
root of this branch.

## Layout

```
index.html          the whole page (hand-written; no build step, no framework)
static/css/         one stylesheet
static/js/          stages.js (system-diagram canvas animations)
static/data/        pose.json, actions.json, segments.json — data the canvas plays back
static/images/      video posters + the axis figure
static/videos/      all result clips (~47 MB)
serve.py            local review server WITH HTTP Range support — use this, not
                    `python -m http.server`, or video seeking silently fails
```

Every asset reference in `index.html` is **relative**, so the page works both at a domain
root and under a subpath such as `/Marionette/`. Keep it that way — a leading `/` in any
`src`/`href` would break the site the moment it is served from a project subpath.

## Local review

```bash
python serve.py 8080      # then open http://localhost:8080/
```

## Where this comes from

The source of truth is `project_page/` in the private `Sarfflow/VideoX-Fun` repo
(branch `continue-9000`). `index.html` is edited there; `static/` is generated by
`project_page/build_assets.py`, which transcodes clips straight out of the `samples/`
tree on the cluster. To update this repo:

```bash
bash project_page/publish.sh          # in the VideoX-Fun checkout
```

It syncs onto `gh-pages` and refuses to run if the checkout is on another branch — `rsync
--delete` aimed at `main` would erase the code and commit that as a page sync.

Do not hand-edit `index.html`, `serve.py` or `static/` here — the next sync overwrites them.
This README is not synced, so it is edited in place.

## One thing that stayed true after going public

A GitHub Pages site is **reachable by anyone who has the URL**, whatever the repository's
visibility. Access-controlled Pages exists only for organizations on GitHub Enterprise Cloud.
So there was never a configuration that served this page to us alone, which is why nothing was
enabled until the flip was deliberate.

`.nojekyll` is present so GitHub serves the tree verbatim instead of running it through Jekyll.
